# 🎪 VK Bot & Admin Panel для управления форумом

Комплексное решение для проведения конференций, форумов и других мероприятий. Проект состоит из двух частей: **Telegram/VK-бота** для участников и **веб-админ-панели** на Streamlit для организаторов.

## ✨ Основные возможности

### 🤖 Для участников (VK Бот)
*   **Регистрация**: Заполнение анкеты (ФИО, организация, контакты) с шифрованием персональных данных (Email, Телефон).
*   **Модерация**: Новые пользователи попадают в статус `pending` и ждут одобрения администратора.
*   **QR-код**: Генерация персонального QR-кода для быстрого прохода на мероприятие (доступна после одобрения).
*   **Программа**: Просмотр расписания докладов, спикеров и локаций. Возможность добавить доклад в избранное.
*   **Карта**: Просмотр схемы площадки по команде `/map`.
*   **Вопросы спикерам**: Возможность задать вопрос анонимно или открыто.
*   **FAQ**: Быстрые ответы на частые вопросы (парковка, Wi-Fi, дресс-код и т.д.).
*   **Отзывы**: Оценка прошедших докладов и обратная связь.

### 🖥 Для организаторов (Streamlit Админ-панель)
*   **Дашборд**: Общая статистика (подтвержденные участники, ожидающие, вопросы на модерации).
*   **Пользователи**: Модерация заявок (одобрение/отклонение), просмотр базы участников.
*   **Вопросы**: Ответы на вопросы от пользователей прямо из админки (с отправкой уведомления в VK).
*   **Программа и Спикеры**: Добавление и удаление докладов, локаций и спикеров.
*   **Карта**: Загрузка и обновление изображения карты площадки (файл `venue_map.jpg`).
*   **Отзывы**: Просмотр оценок и комментариев к докладам.
*   **FAQ**: Управление частыми вопросами.
*   **Рассылка**: Массовая отправка сообщений всем подтвержденным участникам.

## 🛠 Технологический стек
*   **Язык**: Python 3.10+
*   **Бот**: `vkbottle`
*   **Админ-панель**: `Streamlit`
*   **База данных**: `SQLite` (с поддержкой WAL-режима)
*   **Шифрование**: `cryptography` (Fernet)
*   **Генерация QR**: `qrcode`
