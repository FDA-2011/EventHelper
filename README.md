# 🎪 VK Bot & Admin Panel — система управления форумом

Комплексное решение для проведения конференций, форумов и других мероприятий. Проект состоит из двух частей: **VK-бота** для участников и **веб-админ-панели** на Streamlit для организаторов.

Бот и административная панель работают с общей базой данных SQLite.

## ✨ Основные возможности

### 🤖 Для участников (VK-бот)

- **Регистрация** — заполнение анкеты (ФИО, организация, контакты) с шифрованием персональных данных (Email, телефон).
- **Модерация** — новые пользователи получают статус `pending` и ожидают одобрения администратора.
- **QR-код** — генерация персонального QR-кода для быстрого прохода на мероприятие (доступна после одобрения).
- **Программа** — просмотр расписания докладов, информации о спикерах и локациях. Возможность добавлять доклады в избранное.
- **Карта** — просмотр схемы площадки с помощью команды `/map`.
- **Вопросы спикерам** — возможность задавать вопросы анонимно или открыто.
- **FAQ** — быстрые ответы на частые вопросы (парковка, Wi-Fi, дресс-код и т. д.).
- **Отзывы** — оценка прошедших докладов и возможность оставить обратную связь.

### 🖥 Для организаторов (Streamlit-админ-панель)

- **Дашборд** — общая статистика: количество подтверждённых участников, ожидающих одобрения заявок и вопросов на модерации.
- **Пользователи** — модерация заявок (одобрение и отклонение), просмотр базы участников.
- **Вопросы** — ответы на вопросы пользователей непосредственно из админ-панели с отправкой уведомлений в VK.
- **Программа и спикеры** — добавление и удаление докладов, локаций и информации о спикерах.
- **Карта** — загрузка и обновление изображения карты площадки (`venue_map.jpg`).
- **Отзывы** — просмотр оценок и комментариев к докладам.
- **FAQ** — управление списком часто задаваемых вопросов.
- **Рассылка** — массовая отправка сообщений всем подтверждённым участникам.

## 🛠 Технологический стек

| Компонент | Технология |

## 🚀 Развертывание и запуск

### 1. Подготовка (Prerequisites)

Перед началом работы убедитесь, что установлены:

- **Python 3.10 или новее**;
- **Git**;
- аккаунт ВКонтакте и созданное сообщество (для получения токена доступа).

### 2. Клонирование репозитория и установка зависимостей

Откройте терминал и выполните следующие команды:

```bash
git clone https://github.com/ваш_ник/Hakaton_final.git
cd Hakaton_final
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его.

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

Установите необходимые библиотеки:

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корневой папке проекта (рядом с `run.py`) и добавьте следующие настройки:

```env
VK_BOT_TOKEN=ваш_токен_сообщества
OPERATOR_PEER_ID=123456789
ADMIN_IDS=123456789,987654321
WEB_ADMIN_PASS=admin123
```

**Описание переменных:**

| Переменная | Назначение |
|---|---|
| `VK_BOT_TOKEN` | Токен доступа сообщества ВКонтакте |
| `OPERATOR_PEER_ID` | ID диалога оператора |
| `ADMIN_IDS` | Список ID администраторов через запятую |
| `WEB_ADMIN_PASS` | Пароль для входа в веб-админ-панель |

### 4. Настройка шифрования

Для шифрования персональных данных используется библиотека `cryptography` (Fernet).

При первом запуске проекта автоматически создаётся файл `secret.key`, в котором хранится ключ шифрования.

**Важно:**
- Не удаляйте и не изменяйте файл `secret.key`, иначе доступ к ранее зашифрованным персональным данным может быть потерян.
- Не публикуйте этот файл в GitHub и не передавайте посторонним.
- Если бот и админ-панель запускаются на разных компьютерах, необходимо скопировать один и тот же `secret.key` на оба компьютера.

### 5. Настройка сообщества ВКонтакте

Для работы бота необходимо настроить сообщество ВКонтакте.

1. Откройте **Управление сообществом → Настройки → Работа с API**.
2. Перейдите во вкладку **Ключи доступа** и создайте ключ с необходимыми правами на управление сообществом и работу с сообщениями.
3. Скопируйте полученный токен в переменную `VK_BOT_TOKEN` файла `.env`.
4. Перейдите во вкладку **Long Poll API** в настройках сообщества.
5. Включите Long Poll API и выберите актуальную версию API.
6. Во вкладке **Типы событий** включите получение необходимых событий:
   - входящие сообщения;
   - действия пользователей.
7. В разделе **Сообщения** включите опцию «Сообщения сообщества».

### 6. Запуск проекта

Для работы системы необходимо запустить два компонента в отдельных терминалах. В обоих терминалах должно быть активировано виртуальное окружение.

**Терминал № 1 — запуск VK-бота:**

```bash
python run.py
```

При запуске бот инициализирует базу данных `bot.db` и начинает принимать сообщения от пользователей.

**Терминал № 2 — запуск административной панели:**

```bash
streamlit run streamlit_app.py
```

После запуска админ-панель будет доступна в браузере по адресу:

[http://localhost:8501](http://localhost:8501)

## 📌 Структура работы системы

- Участники взаимодействуют с системой через VK-бота.
- Организаторы управляют мероприятием через веб-админ-панель.
- Все данные хранятся в общей базе SQLite.
- Изменения, внесённые через админ-панель, доступны боту, и наоборот.

**Важно:** для корректной работы обоих компонентов необходимо обеспечить доступ к одной и той же базе данных и использовать одинаковый файл `secret.key` для шифрования и расшифровки персональных данных.
