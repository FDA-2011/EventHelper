# VK Forum Bot

Бот для сопровождения мероприятия во ВКонтакте. Python + vkbottle + SQLite.

## Запуск

1. Установите Python 3.10 или новее.
2. Создайте сообщество VK и включите сообщения сообщества.
3. В настройках сообщества откройте «Работа с API» -> «Ключи доступа», создайте ключ с правом управления сообщениями.
4. Скопируйте `.env.example` в `.env` и вставьте ключ в `VK_BOT_TOKEN`.
5. Укажите ID администраторов в `ADMIN_IDS`, ID оператора в `OPERATOR_PEER_ID`.
6. Установите зависимости: `python -m pip install -r requirements.txt`.
7. Запустите: `python run.py`.
8. В «Работа с API» включите Long Poll API и события сообщений. Для приветствия при вступлении включите событие вступления в сообщество.

Бот работает через Long Poll. Сервер/хостинг должен оставаться включённым.

## Команды участника

- `/start` — помощь
- `/register` — регистрация и QR-бейдж
- `/cancel_reg` — отменить регистрацию
- `/edit_reg` — изменить данные регистрации
- `/program` — программа мероприятия; рядом с докладами указан ID
- `/search слово` — поиск доклада или спикера
- `/schedule_add ID` — добавить доклад в личное расписание
- `/schedule_remove ID` — удалить доклад из личного расписания
- `/my_schedule` — отправить личный календарь `.ics`
- `/map` — карта площадки
- `/route откуда куда` — ссылка на маршрут в Яндекс Картах
- `/speaker ФИО` — профиль спикера
- `/ask` — задать вопрос спикеру
- `/find регион или компания` — поиск зарегистрированных участников
- `/poll` — оценить первый доклад
- `/faq` — частые вопросы
- `/support` и `/end_support` — связь с оператором

## Команды администратора

- `/broadcast текст` — рассылка зарегистрированным участникам
- `/emergency текст` — экстренное уведомление

В `ADMIN_IDS` указываются именно VK ID администраторов. Для пересылки обращений `OPERATOR_PEER_ID` должен быть доступен боту в личных сообщениях.

## Данные мероприятия

Демо-спикеры, программа и FAQ находятся в `config.py`. При первом старте они добавляются в `bot.db`, если соответствующие таблицы пустые. Перед реальным мероприятием замените демо-данные на актуальные.

Координаты площадки задаются в `.env` (долгота,широта). Сейчас указаны демонстрационные координаты — обязательно замените их.

## CRM

По умолчанию `CRM_ENABLED=0`: регистрация работает автономно, ID формируется локально. Для реальной CRM включите `CRM_ENABLED=1`, задайте `CRM_API_URL` и `CRM_API_KEY`. Ожидается endpoint `POST /register`, принимающий JSON с данными регистрации и возвращающий JSON с полем `id` или `crm_id`. При другом API адаптируйте `crm_register()` в `helpers.py`.

## Важные ограничения

- VK не разрешает боту первым писать произвольным пользователям, пока пользователь не открыл диалог/не нажал «Начать» или не выполнил допустимое действие. Поэтому массовые рассылки могут быть доставлены не всем.
- Push по расписанию и интеграция с внешней системой голосования требуют реального API/планировщика и здесь не подключены.
- Маршруты используют ссылки Яндекс Карт; координаты и названия точек необходимо настроить под площадку.
- Не публикуйте `.env`, ключ сообщества и базу с персональными данными в открытом репозитории.
